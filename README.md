# PANAFACOM LKIT-16 EMULATOR
![LKIT-16](https://github.com/yanataka60/LKIT-16_Emulator/blob/main/PNG/MAIN%20PANEL.png)

　PANAFACOM LKIT-16のEmulatorを作ってみました。

　動作には実機のMonitor-ROMのバイナリファイルが必要です。

　また、BASIC-ROM、CG-ROMのバイナリファイルがあればBASICも動作可能です。

## MONITOR-ROMの吸い出し(必須)
　大きく分けて３つの方法があると思います。

### 1)自力で吸い出せる方
　一つだけ注意してほしいのは基板上では左側のROMが上位バイト、右側のROMが下位バイトのデータとなっており、Emulatorでは２つの内容を合成したLKIT-16 ROM.binというファイルにする必要があります。

### 2)ユーザーズマニュアルに掲載されているアセンブルリストからバイナリデータを打ち込む。
　手間と時間が掛かりますが、確実な方法と言えるとは思います。

### 3)モニタコマンドからCMTにSAVEする操作を行い、パソコンにWAVファイルとして保存し、バイナリファイルに変換する。
　MONITOR-ROMをそのままCMTにSAVEする操作は拒否されてしまうのでちょっと手間が掛かりますが、確実ではあります。

#### 手順
　ROMを256語ずつRAMへコピーし、4回に分けてSAVEします。

　作業には0040～0052と1000～10FFを使用しますので1000～10FFにRAMが実装されていないと実行できません。

##### 1. コピープログラムを入力する
　以下のプログラムをパネルから入力します。

|アドレス|入力値|処理|
| ------------ | ------------ | ------------ |
|0040|C350|コピー元を取得|
|0041|C451|コピー先を取得|
|0042|C252|ワード数を取得|
|0043|E000|ROMから1ワード読む|
|0044|A800|RAMへ1ワード書く|
|0045|4B01|コピー元を進める|
|0046|4C01|コピー先を進める|
|0047|4241|残りワード数を減らす|
|0048|C743|コピーを繰り返す|
|0049|C749|完了後、ここで待機|

##### 2. コピー条件を設定する
|アドレス|入力値|意味|
| ------------ | ------------ | ------------ |
|0050|0100|コピー元ROMの開始番地|
|0051|1000|コピー先RAMの開始番地|
|0052|0100|コピーする数(256ワード)|

##### 3. コピーを実行する
　開始番地0040を設定してRUNを押し実行します。

　コピーはすぐに終了し、0049で待機します。少し待ってSTOPを押し、モニタへ戻してください。

|アドレス|入力値|
| ------------ | ------------ |
|0017|0040|

##### 4. コピーしたRAMをSAVEする
　保存開始・終了番地を設定します。

|アドレス|入力値|
| ------------ | ------------ |
|000C|1000|
|000D|10FF|

　PCで録音を開始してから、ST／R1 → FUNCを押し、SAVE処理を実行します。

　SAVE処理が完了したら録音を停止し、ROM0100.wavとして保存します。

##### 5. 残りの3区間も保存する
　0050番地を次表の値へ変更し、手順3から繰り返します。0051・0052とSAVE範囲は同じです。

|回|0050の設定値|元のROM範囲|wavファイル名|
| ------------ | ------------ | ------------ | ------------ |
|1|0100|0100～01FF|ROM0100.wav|
|2|0200|0200～02FF|ROM0200.wav|
|3|0300|0300～03FF|ROM0300.wav|
|4|0400|0400～04FF|ROM0400.wav|

##### 6. WAVをBINに変換します
　Wav2Binフォルダのlkit16_wav2bin.exeを使ってバイナリファイルに変換します。コマンドラインで実行してください。

|実行コマンド|
| ------------ |
|lkit16_wav2bin ROM0100.wav ROM0100.bin|
|lkit16_wav2bin ROM0200.wav ROM0200.bin|
|lkit16_wav2bin ROM0300.wav ROM0300.bin|
|lkit16_wav2bin ROM0400.wav ROM0400.bin|
|copy /b ROM0100.bin +ROM0200.bin +ROM0300.bin +ROM0400.bin "LKIT-16 ROM.bin"|

　LKIT-16 ROM.binが出来上がるはずです。

## BASIC-ROMの吸い出し(任意)
　BASIC-ROMも同様に吸い出します。BASIC-ROMの配置アドレスは次の通りです。

|配置先（ワードアドレス）|作成ファイル名|サイズ|
| ------------ | ------------ | ------------ |
|0500H～08FFH|BASIC-ROM1.Bin|2,048バイト|
|D800H～DFFFH|BASIC-ROM2.Bin|4,096バイト|

## CG-ROMの吸い出し(任意)
　CG-ROMはプログラムでは読み出せないので吸い出す必要があります。

　吸い出せない方は、Windowsフォントから疑似的にフォントファイルを作ることが出来ます。

　LKIT-16 Emulatorのツールから「WindowsフォントからTVフォントを作成」を実行してください。元とするフォントを選んでOKをクリックすると保存ファイル名の入力になります。

　TVFONT.BINと入力されていますのでそのまま「保存」をクリックすればTVFONT.BINが出来上がります。

　次回LKIT-16 Emulator起動時に読み込まれるようになります。

## 使い方
　適当なフォルダにLkit16Emulator.exe、LKIT-16 ROM.binを置き、ダブルクリック等で起動させます。

　起動した状態でメインパネルが操作可能になります。

![LKIT-16](https://github.com/yanataka60/LKIT-16_Emulator/blob/main/PNG/MAIN%20PANEL.png)

　メインパネルの操作はマウスでのクリック操作となりますが、メインパネルがアクティブなときには次のキーがWindowsキーボードに割り当てられています。

|メインパネルの操作|Windowsキー|備考|
| ------------ | ------------ | ------------ |
|STOP|F5||
|RUN|F6||
|FUNC|F7||
|CANCL|F8||
|SET ADRS|F9||
|ASMBL|F10||
|STORE|F11又はENTER||
|DISP|F12||
|L/R0|F1||
|ST/R1|F2||
|B/R2|F3||
|BAL/X0|F4||
|0～9|0～9|テンキーも可|
|A|A又はテンキーの/||
|B|B又はテンキーの*||
|C|C又はテンキーの-||
|D|D又はテンキーの+||
|E|E又はテンキーのENTER||
|F|F又はテンキーの.||

### ファイル入出力
　バイナリファイルの読込、保存の方法は二通りの方法があります。

#### BIN/BTKメモリ入出力
　バイナリファイルを直接RAMにロード、RAMからセーブします。

![Memory INOUT](https://github.com/yanataka60/LKIT-16_Emulator/blob/main/PNG/MEMORY%20IO.png)

##### BIN読込
　BIN読込開始アドレスを16進数4桁で指定して拡張子binのバイナリファイルをLOADします。
##### BTK読込
　拙作LKIT-16_SDで使用している保存形式BTKファイルを読み込みます。BTKファイルには読込開始アドレス、読込バイト数の情報があるのでアドレス等の情報を指定する必要はありません。
##### BIN保存
　設定した保存範囲を単純なバイナリファイルとして指定したファイル名で保存します。拡張子はBINとなります。
##### BTK保存
　設定した保存範囲を拙作LKIT-16_SDで使用している保存形式BTKファイルとして指定したファイル名で保存します。拡張子はBTKとなります。

#### カセットWAV読込
　読み込むWAVファイルを選択した後にL/R0,FUNCとCMT読込操作を行ってください。

#### カセットWAV保存
　保存するWAVファイル名を入力又は選択した後にST/R1,FUNCとCMT保存操作を行ってください。

　ファイルはWAVファイルとなります。

### BASIC起動
　BASIC-ROMのバイナリファイル、CG-ROMのバイナリファイルが必要です。

　MONITOR-ROMと同様にLkit16Emulator.exeと同じフォルダにBASIC-ROM1.Bin、BASIC-ROM2.Bin、TVFONT.binを置いておいてください。起動時に読み込まれます。

　その状態でツールの「BASIC起動(D800H)」をクリックするとTV画面のWindowが開き、BASICが使えます。

![BASIC](https://github.com/yanataka60/LKIT-16_Emulator/blob/main/PNG/BASIC.png)

### CPUレジスタ表示
　CPUの現在のレジスタ値が表示されます。ユーザープログラム実行中であれば、任意にSTOPが出来、STEP動作も可能です。

　また、CONTをクリックすることで再開することも可能です。

![REGISTER](https://github.com/yanataka60/LKIT-16_Emulator/blob/main/PNG/REGISTER.png)

## CMTツール
　実機とのCMT WAVデータとWindows PCが扱うバイナリデータと相互変換できるツールを作りました。
### Wav2Bin
　実機でCMTへのSAVE操作をした時のWAVファイルをWindows PCで扱うバイナリデータに変換します。

　基本的な使い方は次の通りです。

　例) lkit16_wav2bin 入力.wav 出力.bin

### Bin2Wav
　Windows PCで作成したバイナリファイルを実機でCMT LOAD操作で読み込めるWAVデータに変換します。

　アドレス情報のない通常のbinファイルとLKIT-16_SDで扱うアドレス情報を持ったBTKファイルのどちらも変換できます。

#### BTKファイル
　アドレス情報を持っていますので入力.btk、出力.wavを指定するだけです。

　例) lkit16_bin2wav 入力.btk 出力.wav

#### BINファイル
　アドレス情報を持っていないのでLOAD開始アドレスの指示が必要です。

　例) lkit16_bin2wav 入力.bin 出力.wav --start 0040
